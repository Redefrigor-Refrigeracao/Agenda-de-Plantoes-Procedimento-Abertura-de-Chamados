Acesso restrito

Somente quem tem permissão de escrita no repositório do site consegue alterar a escala.

Como gerar o token (uma única vez):
  1. No GitHub, acesse Settings → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque o repositório deste site.
  3. Em Permissions → Contents, selecione Read and write.
  4. Gere o token, copie e cole acima. Não compartilhe com ninguém.
